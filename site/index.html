Behaviour

It picks what to do next.
Never the same thing twice.

Between your interactions it lives on its own: idle motion, glances, blinks, and actions blended on top by a director.

Idle life that never stops

Breathing, weight shifts, blinks (fast to close, slower to open), glances.

Reactions

Hover and it notices you and waves. Click and it jumps in surprise.

Actions

Wave, draw, morph, select, stretch, snap, idea, heart, spin, sleepy, hop, surprise.

Light

Each SVG is a few KB; the whole kit has no runtime dependencies.

Polite

Pauses off screen and in hidden tabs; reduced motion holds a still pose.

One mascot, 50 styles

The anatomy says what is drawn. The style says how.

Anatomies never pick colours: they ask the style for a role (body, belly, eye…), so every mascot works in every style. No two styles share more than 3 of 7 axes, and a visual check fails if two look alike.

Forms

Some styles rebuild the character, not just repaint it.

A form sets proportions, corners, limb taper, hands, feet and an eye, mouth and brow model. Nodi, the robot, the fox and the ghost are redrawn in each shape language, and every action still plays.

How it works

Six parts, all in code.

01 · anatomies/

An anatomy

The skeleton: parts, real pivots, channels, built-in life and actions.

02 · kit/rig.ts

A seamless rig

Each layer drawn twice, outlines first and fills on top, so joints never show a seam.

03 · kit/motion.ts

One clock

Smooth paths through key poses, never stopping dead at each one.

04 · kit/spring.ts

Springs

Handles, tails, antennas, props and the gaze trail the body a beat later.

05 · kit/morph.ts

Shape morphs

A rounded square becomes a circle, a star or a heart, point by point.

06 · kit/director.ts

A director

Blends actions over the idle life and reacts to you.

Make your own

A mascot is one JSON file. No engine code.

Pick an anatomy, a palette, proportions and props, then add actions as keyframes on named channels.

Then pnpm check my-mascot runs every rule in CRAFT.md, frame by frame: in frame, no jumps, a good rest pose, budget. Green means it ships.

Read CRAFT.md →
mascots/my-mascot/mascot.json
{
  "name": "my-mascot",
  "title": "My Mascot",
  "anatomy": "anchor",
  "palette": {
    "body": "#FFB547", "eye": "#2A1A08",
    "accent": "#5B63E8", "prop": "#E5383B"
  },
  "props": { "heart": [0, -80] },
  "actions": [{
    "name": "love", "duration": 2400,
    "tracks": [
      { "ch": "prop.heart", "op": "set",
        "keys": [[0, 0], [2400, 1]] },
      { "ch": "eyes.happy",
        "keys": [[0, 1], [2400, 1]] }
    ]
  }]
}
